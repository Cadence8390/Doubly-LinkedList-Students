# Doubly-LinkedList-Students

A C++ program that uses a doubly linked list to store and manage student records. This project demonstrates pointer-based data structures, dynamic memory management, and the manipulation of structured data.

# Features

Stores student records in a doubly linked list

Supports modifying student information

Uses links to both the next and previous nodes

Demonstrates dynamic data management using pointers

# How to Run (Visual Studio)

Download the repository as a ZIP file from GitHub.

Extract the ZIP file to a convenient location.

Open the extracted folder and locate the .sln file.

Double-click the .sln file to open the project in Visual Studio.

In Visual Studio, select Debug → Start Without Debugging to build and run the program.
